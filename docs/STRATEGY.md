# Estrategia de Producto: RGIA Master (Base vs. Pro)

Este documento define la visión estratégica y la diferenciación entre las dos versiones de la plataforma RGIA Master.

## Visión General

La estrategia de producto se basa en un modelo de dos niveles:

1.  **RGIA Master (Versión Base):** Una solución **gratuita y de código abierto** diseñada para ser la puerta de entrada perfecta a la IA empresarial. Es robusta, segura y resuelve el caso de uso más común: hacer preguntas sobre documentos basados en texto.
2.  **RGIA Master (Versión Pro):** Una solución **comercial o de suscripción** que se construye sobre la base sólida de la versión gratuita, añadiendo capacidades avanzadas para resolver problemas empresariales complejos y ofrecer una gestión centralizada.

## Contenido Detallado de Cada Versión

| Característica | RGIA Master (Versión Base) | RGIA Master Pro (Visión a Futuro) |
| :--- | :---: | :---: |
| **Instalación Automatizada** | ✅ (Script único) | ✅ |
| **Tipo de Documentos (RAG)** | Solo Texto (PDF, TXT, MD) | **Soporte Multi-Modal (Texto, Imágenes, Audio)** |
| **Búsqueda y Razonamiento** | Búsqueda Semántica | **RAG con Grafos de Conocimiento** |
| **Panel de Control Interno** | Dashboard Estático | **RGIA Control Center Avanzado** |
| **Seguridad** | ✅ (100% On-Premise) | ✅ (Además de **RBAC**) |
| **Costo / Licencia** | **Gratuita y de Código Abierto** | **Comercial o de Suscripción** |

## Razonamiento Estratégico

### 1. RGIA Master (Versión Base)
- **Propósito:** Democratizar y simplificar. Eliminar las barreras para que cualquier empresa pueda empezar a experimentar con una plataforma RAG privada y segura.
- **Público Objetivo:** PYMEs, equipos de desarrollo, laboratorios de innovación.
- **Propuesta de Valor:** Una solución "problema resuelto". Con un solo comando, obtienes una plataforma de nivel profesional, segura y gratuita, sin depender de nubes costosas ni de hardware especializado (GPU).

### 2. RGIA Master (Versión Pro)
- **Propósito:** Resolver problemas complejos y ofrecer una gestión centralizada a nivel empresarial.
- **Público Objetivo:** Empresas más grandes con diversos tipos de datos y necesidades de analíticas, control de acceso y capacidades de razonamiento más profundas.
- **Propuesta de Valor:** Es la ruta de "upgrade" natural para responder a preguntas más complejas como: *"¿Y si ahora quiero preguntarle cosas a las imágenes de mis PDFs?"* o *"¿Cómo puedo gestionar quién tiene acceso y ver quién pregunta qué?"*.
